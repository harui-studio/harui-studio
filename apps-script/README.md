# 客製詢問收件設定（Google Apps Script）

用店家自己的 Google 帳號操作，詢問資料只存在店家的試算表與雲端硬碟。約 10 分鐘。

## 步驟

1. 建立一份新的 Google 試算表，命名例如「春豬官網｜客製詢問」。
2. 試算表選單 **擴充功能 → Apps Script**。
3. 刪掉編輯器裡原本的內容，貼上本資料夾的 `Code.gs` 全部內容，儲存。
4. （選用）要收通知信：把第 16 行改成
   `const NOTIFY_EMAIL = 'haruistudio@gmail.com';`
5. 上方函式選單選 `setup` → **執行**，依畫面完成授權（會出現「Google 尚未驗證這個應用程式」，選「進階 → 前往」即可，這是你自己的程式）。
   完成後試算表會多一個「客製詢問」工作表。
6. 右上角 **部署 → 新增部署作業**
   - 類型：**網頁應用程式**
   - 執行身分：**我**
   - 存取權：**所有人**
   - 按「部署」，複製「網頁應用程式網址」（`https://script.google.com/macros/s/.../exec`）。
7. 把網址填入官網 `content/site.json` 的 `inquiryEndpoint`（或在後台「網站內容 → 客製表單收件網址」），儲存並等網站重新發布。
8. 到官網「客製材料包」頁實際送一筆測試，確認：
   - 網頁顯示「已收到你的詢問」與編號
   - 試算表出現該筆資料
   - （有設定的話）收到通知信

## 日常使用

- 每筆詢問一列；「處理狀態」欄可選：新詢問／已回覆／已報價／已成立／不接單。
- 參考圖片存在雲端硬碟「春豬官網｜客製詢問圖片」資料夾，只有店家能看。
- 試算表可用篩選、加欄位寫備註；請不要改第一列欄位名稱的順序。

## 修改程式後

改了 `Code.gs` 要重新發布：**部署 → 管理部署作業 → 編輯 → 版本選「新版本」→ 部署**。網址不變，不需改官網。

## 注意

- 通知信使用 Google 帳號的每日寄信額度（一般帳號約 100 封/天），寄信失敗不影響收件。
- LINE 通知需另外串接 LINE Messaging API，目前未啟用。
